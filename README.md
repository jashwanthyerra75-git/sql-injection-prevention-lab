SQL Injection Prevention Lab

A beginner-friendly Python and SQLite project demonstrating secure authentication and SQL injection prevention.

Features

- SQLite database for user records
- Password hashing using PBKDF2-HMAC with a random salt
- Parameterized SQL queries to reduce SQL injection risk
- Secure password comparison
- Basic login success and failure handling

Technologies

- Python 3
- SQLite
- Git and GitHub

Run Locally

1. Install Python 3.

2. Download or clone this repository.

3. Run the application:
   
   "python main.py"

Security Concepts Demonstrated

- Password hashing and salting
- Parameterized database queries
- Authentication failure handling
- Keeping local database files out of version control
